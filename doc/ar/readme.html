إضافة Gemini Voice Typing لـ NVDA

إضافة لبرنامج NVDA توفر كتابة صوتية عالية الجودة ومتعددة اللغات باستخدام نماذج الذكاء الاصطناعي من Google Gemini. تتميز بالإملاء اللحظي، ووضع الكتابة الذكي، وتصحيح إملائي ولغوي متطور.

أوضاع الكتابة (النماذج)

توفر الإضافة نموذجين قويين للكتابة حسب احتياجك:

  1. الوضع السريع (Strict Live Mode): يعمل بنموذج gemini-3.5-transcribe-live. هذا الوضع يكتب لحظياً كلمة بكلمة أثناء حديثك. يتميز بسرعة فائقة وممتاز للإملاء السريع والمحادثات.
  2. الوضع الذكي (Smart Batch Mode): يعمل بنموذج gemini-3.5-flash-lite. هذا الوضع يجمع صوتك وينتظر حتى تصمت لمدة ثانية واحدة أو تضغط Enter. يقوم بتحليل الجملة بالكامل لضبط القواعد بدقة متناهية، والتفريق المثالي بين الكلمات العربية والإنجليزية دون أي أخطاء (عربيزي). يأخذ ثانية إضافية ولكنه يقدم نتائج خالية من العيوب.

يمكنك التبديل بين الوضعين بكل سهولة في أي وقت بالضغط على NVDA + Alt + Shift + G. (ملاحظة هامة: إذا قمت بالتبديل أثناء عمل الميكروفون بالفعل، يجب عليك إيقاف وتشغيل التسجيل مرة أخرى ليتم تطبيق الوضع الجديد والأوامر الخاصة به).

وضع الإدخال اليدوي (Manual Commit Mode)

بشكل افتراضي، تقوم الإضافة بكتابة النص تلقائياً بمجرد صمتك. ولكن إذا أردت التحكم الكامل في متى يتم إرسال النص (مثل تطبيقات الدردشة)، يمكنك تفعيل الوضع اليدوي بالضغط على NVDA + Alt + G.

عند تفعيل هذا الوضع:

  1. يستمع الميكروفون ويجمع كلامك في الخلفية باستمرار.
  2. لن يتم كتابة أي شيء حتى تضغط على Enter أو Space (المسافة).
  3. اضغط Escape (الهروب) للخروج من الوضع اليدوي ومسح الكلام الذي لم يُكتب.

اختصارات لوحة المفاتيح

  • NVDA + Shift + G: تشغيل / إيقاف الكتابة الصوتية
  • NVDA + Alt + Shift + G: التبديل بين الوضع السريع والوضع الذكي
  • NVDA + Alt + G: تشغيل / إيقاف وضع الإدخال اليدوي
  • NVDA + G: تشغيل / إيقاف المصحح الإملائي واللغوي (Corrector)

(يمكنك تغيير هذه الاختصارات من قائمة NVDA -> تفضيلات -> اختصارات الإدخال -> Gemini Voice Typing)

نصائح لأفضل أداء

  • تحدث بجمل قصيرة أو متوسطة: للحصول على دقة مثالية، تحدث بجمل طبيعية وتوقف قليلاً بعد كل فكرة.
  • انتظر نطق NVDA: بعد الصمت أو الضغط على Enter، انتظر حتى ينطق NVDA النص الذي تمت كتابته قبل أن تبدأ في الجملة التالية.

الإعدادات

  1. افتح قائمة NVDA -> تفضيلات -> إعدادات.
  2. اختر Gemini Voice Typing من القائمة.
  3. في حقل Gemini API Keys، الصق مفاتيح الـ API الخاصة بك (مفصولة بفاصلة).
  4. اختر وضع الكتابة المفضل لديك، ويمكنك تعديل الأوامر البرمجية (Prompts) الخاصة بالذكاء الاصطناعي.
  5. اضغط موافق.
