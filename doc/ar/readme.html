إضافة الإملاء الصوتي Gemini لبرنامج NVDA

إضافة سريعة جداً لتحويل الصوت إلى نص في الوقت الفعلي لقارئ الشاشة NVDA، مدعومة بواجهة برمجة تطبيقات Google Gemini Live API. مخصصة ومضبوطة خصيصاً للإملاء ثنائي اللغة (عربي وإنجليزي) بدقة متناهية.

المميزات

  • إملاء في الوقت الفعلي: تقوم الإضافة ببث الصوت مباشرة إلى Gemini Live API وإدراج الكلمات المستخرجة في حقل النص النشط أثناء التحدث.
  • وضع اللصق الخفي: يتم إدراج النص بسرعة البرق وبدقة عالية باستخدام تقنية تجاوز ذكية للحافظة. تحترم الإضافة برامج إدارة الحافظة (مثل ClipHistory و Win+V) وتخفي النص مؤقتاً حتى لا يلوث سجل الحافظة الخاص بك. هذا هو الوضع الافتراضي، لكن يمكنك تفعيل ميزة نسخ النص للحافظة من الإعدادات.
  • تفوق متعدد اللغات: تنتقل الإضافة بسلاسة بين اللغات. مضبوطة بدقة لاتباع قواعد الإملاء العربية الصارمة. يمكنك دمج اللغتين العربية والإنجليزية في نفس الجملة بسلاسة.
  • نظام النسخ الاحتياطي للمفاتيح: يمكنك وضع عدة مفاتيح API مفصولة بفواصل (مثال: key1, key2, key3). إذا استهلك أحد المفاتيح حصته، ستنتقل الإضافة تلقائياً للمفتاح التالي بدون أي انقطاع.
  • تنبيهات صوتية واضحة: أصوات مميزة لبدء الإملاء، الإيقاف، الأخطاء، مع إمكانية تفعيل رنين مزدوج عند تغيير مفتاح الـ API تلقائياً.
  • توافق شامل: تعمل الإضافة عبر جميع حقول النصوص، المحررات، وتطبيقات ويندوز دون أي قيود على مكان الكتابة.

اختصارات لوحة المفاتيح

  • NVDA + Shift + G: بدء / إيقاف الإملاء الصوتي

(يمكنك أيضاً تخصيص الاختصار من خلال قائمة NVDA -> التفضيلات -> إيماءات الإدخال -> Gemini Voice Typing)

الإعداد والتهيئة

  1. افتح إعدادات NVDA بالضغط على NVDA + N، ثم انتقل إلى التفضيلات (Preferences) -> الإعدادات (Settings).
  2. انتقل إلى Gemini Voice Typing في قائمة الفئات.
  3. في حقل Gemini API Keys، أدخل مفتاحاً أو أكثر من مفاتيح واجهة برمجة التطبيقات مفصولة بفواصل.
  4. (اختياري) يمكنك تفعيل خيار إصدار تنبيه صوتي (رنتين) عند انتقال الإضافة تلقائياً إلى مفتاح احتياطي.
  5. (اختياري) يمكنك تفعيل خيار "النسخ التلقائي للنص إلى الحافظة" (Auto copy result to clipboard) إذا كنت ترغب في حفظ النصوص التي تمليها داخل سجل الحافظة.
  6. اضغط على موافق (OK) لحفظ التغييرات.
