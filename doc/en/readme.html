Gemini Voice Typing for NVDA

An NVDA add-on that provides high-quality, multilingual voice typing using the Google Gemini Live API. Features real-time dictation with advanced AI-powered spelling and grammar correction.

Best Practices for Optimal Performance

  • Speak in Short or Medium Phrases: To ensure absolute accuracy and prevent words from dropping, do not dictate a single extremely long sentence all at once. Speak in short or medium-length phrases.
  • Pause After Speaking: Pause briefly (for about one second) after you finish a thought to allow the add-on to process, correct, and type the text accurately before you start your next sentence.
  • Wait for NVDA Announcement: After pausing, wait until you hear the screen reader (NVDA) announce "Pasted" or read the inserted text before starting your next sentence. This prevents overlapping audio and system lag.

Smart Shutdown Feature

There is an option in the settings called "Smart Shutdown" (enabled by default). When you press the shortcut to stop voice typing, the microphone is muted instantly, but the add-on waits in the background for 1 extra second before fully disconnecting. This feature ensures that the final words you just spoke (which haven't been pasted yet) have enough time to return from Google's servers and paste successfully, so you don't lose the end of your sentence.

Features

  • Lightning Fast: Uses Gemini Live API for real-time streaming recognition.
  • Silent Typing: Directly types into the text field without NVDA repeatedly announcing every word.
  • Dialect Preservation: Corrects spelling and punctuation without aggressively altering colloquial dialects (e.g., Egyptian Arabic).
  • Auto Key Rotation: Input multiple API keys. If one runs out of quota, it instantly fails over to the next without dropping your dictation.
  • Customizable AI Prompts: Full control over the AI prompts used for both transcription and spelling correction via settings!

Keyboard Shortcuts

  • NVDA + Shift + G: Start / Stop Voice Typing (Normal Mode)
  • NVDA + Alt + G: Toggle Manual Commit Mode
  • Enter or Space: Commit (paste) accumulated speech (only while Manual Commit Mode is active)
  • Escape: Exit Manual Commit Mode without pasting

(You can reassign these via NVDA -> Preferences -> Input Gestures -> Gemini Voice Typing)

Manual Commit Mode

Manual Commit Mode lets you review what you've said before it gets typed. When active:

  1. The microphone listens and accumulates your speech in the background.
  2. Nothing is typed until you press Enter or Space to commit.
  3. Press Escape to exit Manual Commit Mode and discard uncommitted text.

This mode is useful when you want more control over what gets typed, for example in chat applications or when composing important messages.

Note: Enter, Space, and Escape only have special behavior while Manual Commit Mode is active. Outside of it, they work normally with no interference.

Settings & Configuration

  1. Open NVDA Menu (NVDA + N) -> Preferences -> Settings.
  2. Select Gemini Voice Typing from the categories list.
  3. In the Gemini API Keys field, paste your API keys (separated by commas).
  4. Transcription Prompt: Modify the system instructions for the Live listening model.
  5. Correction Prompt: Modify the system instructions for the fast spell-checker model (Flash Lite).
  6. Click OK.
