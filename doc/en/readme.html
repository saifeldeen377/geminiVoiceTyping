Gemini Voice Typing for NVDA

An NVDA add-on that provides high-quality, multilingual voice typing using the Google Gemini APIs. Features real-time dictation, an intelligent batch transcription mode, and advanced AI-powered spelling and grammar correction.

Transcription Modes

This add-on offers two powerful transcription models to suit your needs:

  1. Strict Live Mode (Very Fast): Powered by gemini-3.5-transcribe-live. This is a real-time streaming mode. It types instantly as you speak, word-by-word. It is extremely fast and great for general dictation.
  2. Smart Batch Mode (Perfect Accuracy): Powered by gemini-3.5-flash-lite. This mode collects your speech and waits for you to pause (for 1 second) or press Enter. It analyzes the entire sentence to apply perfect formatting, grammar, and flawlessly mixes English and Arabic words. It takes slightly longer but delivers impeccable results.

You can seamlessly toggle between these modes using NVDA + Alt + Shift + G.

Manual Commit Mode

By default, the add-on types automatically when you pause. However, if you want full control over when the text is inserted, you can activate Manual Commit Mode using NVDA + Alt + G.

When Manual Commit Mode is active:

  1. The microphone listens and accumulates your speech in the background.
  2. Nothing is typed until you press Enter or Space to commit.
  3. Press Escape to exit Manual Commit Mode and discard uncommitted text.

Note: Enter, Space, and Escape only have special behavior while Manual Commit Mode is active.

Keyboard Shortcuts

  • NVDA + Shift + G: Start / Stop Voice Typing
  • NVDA + Alt + Shift + G: Toggle between Strict and Smart modes
  • NVDA + Alt + G: Toggle Manual Commit Mode
  • NVDA + G: Toggle the AI Grammar & Spelling Corrector On/Off

(You can reassign these via NVDA -> Preferences -> Input Gestures -> Gemini Voice Typing)

Best Practices

  • Speak in Short or Medium Phrases: For the best accuracy, dictate in natural sentences and pause briefly after each thought.
  • Wait for NVDA Announcement: After pausing or pressing Enter, wait until you hear NVDA announce the pasted text before starting your next sentence.

Settings & Configuration

  1. Open NVDA Menu (NVDA + N) -> Preferences -> Settings.
  2. Select Gemini Voice Typing from the categories list.
  3. In the Gemini API Keys field, paste your API keys (separated by commas).
  4. Select your preferred transcription mode and adjust the AI system prompts as desired.
  5. Click OK.
