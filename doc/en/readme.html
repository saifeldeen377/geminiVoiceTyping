Gemini Voice Typing for NVDA

The Problem

For blind and visually impaired users, typing long texts, writing code, or seamlessly switching between languages (like Arabic and English) using a keyboard can be time-consuming and tedious. Traditional voice dictation tools often fall short: they struggle with heavy accents, fail miserably when mixing multiple languages in the same sentence, type with noticeable latency, or aggressively filter out colloquial dialects. Furthermore, many dictation tools pollute the system clipboard or constantly trigger screen reader announcements that interrupt the user's train of thought.

The Solution

Gemini Voice Typing is an NVDA add-on that completely solves this problem by harnessing the power of Google's advanced Gemini AI. It acts as an ultra-fast, highly accurate dictation assistant that types directly into your active text field. It seamlessly handles complex bilingual code-switching (e.g., dictating in Arabic and English simultaneously) without transliteration errors. With dedicated smart AI corrector models, it instantly fixes your grammar and spelling, ensuring your dictated text is impeccably formatted before it even reaches your screen.

Setup & Configuration

  1. Download the latest .nvda-addon file from the repository's Releases page.
  2. Install it in NVDA and restart NVDA.
  3. Open NVDA Settings: Press NVDA + N, then go to Preferences -> Settings.
  4. Navigate to Gemini Voice Typing in the categories list.
  5. In the Gemini API Keys field, enter one or more API keys separated by commas (You can generate a free API key from Google AI Studio).
  6. Select your preferred transcription mode and adjust the AI system prompts if desired.
  7. Click OK to save.

Features

  • Dual Transcription Engines:
    • Strict Live Mode: A zero-latency real-time streaming mode powered by gemini-3.5-transcribe-live. It types instantly as you speak, word-by-word.
    • Smart Batch Mode: Powered by gemini-3.5-flash-lite. It collects your speech and intelligently transcribes it when you pause, applying flawless grammar, formatting, and bilingual separation.
  • Manual Commit Mode: Gain full control over your dictation. Dictate freely in the background, and the text is only injected into your application when you explicitly press Enter.
  • AI Grammar & Spelling Corrector: Automatically cleans up, corrects, and formats your text before pasting it.
  • Stealth Paste Mode: Injects text with extreme speed without polluting your clipboard history (bypasses Windows Win+V and ClipHistory).
  • Multi-Key Failover: Input multiple Gemini API keys. If one runs out of quota, it instantly fails over to the next without dropping your dictation!
  • Accessible Audio Feedback: Intuitive earcons (chimes) for starting, stopping, API key rotation, and errors.

Keyboard Shortcuts

  • NVDA + Shift + G: Start / Stop Voice Typing
  • NVDA + Alt + Shift + G: Toggle between Strict Mode and Smart Mode (Note: If changed while recording, you must restart the microphone for the new mode to take effect)
  • NVDA + Alt + G: Toggle Manual Commit Mode
  • NVDA + G: Toggle the AI Grammar & Spelling Corrector On/Off

When Manual Commit Mode is active:

  • Enter or Space: Commit (paste) the accumulated speech
  • Escape: Exit Manual Commit Mode and discard uncommitted text

(All shortcuts can be customized via NVDA Menu -> Preferences -> Input Gestures -> Gemini Voice Typing)

Best Practices

  • Speak in natural phrases: For optimal accuracy and seamless language mixing, avoid dictating a single extremely long sentence without taking a breath. Pause briefly (about 1 second) after each thought.
  • Wait for NVDA announcement: After pausing or pressing Enter, wait until you hear the screen reader announce the pasted text before starting your next sentence to prevent audio overlapping and system lag.
  • Switching Modes: If you toggle the model or corrector while the microphone is already active, you must stop and restart voice typing for the new AI prompts to take effect.
